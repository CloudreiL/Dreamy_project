# Dreamy project

The project is an application for writing dreams and tracking the user emotional state from them

## Used technologies
- Dart
- Flutter
- Firebase
## [Figma Layout](https://www.figma.com/design/NF6roHLK0jbjECEbPn7UfC/Dreamy?t=SwkhzzkdA2Qbfxhw-0)
